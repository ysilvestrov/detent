# CI gate і smoke-перевірка: план реалізації

> **Для агентів:** ОБОВ'ЯЗКОВИЙ СКІЛ: superpowers:subagent-driven-development або superpowers:executing-plans. Кроки позначено чекбоксами (`- [ ]`).

**Мета:** кожен PR і push у `main` перевіряє збірку, тести й те, що запакований `detent` встановлюється й працює на Linux та Windows.

**Архітектура:** `scripts/smoke.mjs` пакує репозиторій, ставить архів у тимчасову теку й перевіряє команди через `node_modules/.bin/detent`. `.github/workflows/ci.yml` запускає `npm run gate` і `npm run smoke` у трьох конфігураціях.

**Стек:** Node (лише вбудовані модулі), GitHub Actions.

**Спека:** `docs/specs/2026-11/2026-11-02-ci-gate-design.md`

## Глобальні обмеження

- Жодного рекурсивного чи автоматичного видалення: правило 8 конституції. Теки `detent-smoke-*` лишаються в `os.tmpdir()`.
- Без публікації, без секретів, без запуску справжніх рецензентів.
- `permissions: contents: read`, `persist-credentials: false`, тригер `pull_request`, не `pull_request_target`.
- `npm run gate` і `files` у `package.json` не змінюються.
- Скрипт працює на Node 20.

## На що дивитись на рев'ю

Кожен рядок перевіряється в задачі 2.

1. Шлях до temp містить пробіл (ім'я користувача Windows, запуск через shell): smoke проходить.
2. Скрипт запускає агент із `DETENT_AUTHOR=claude` або `CROSS_REVIEW_ACTIVE=1`: результат той самий, `cross-review` дає код 2 про `--author`.
3. Temp лежить усередині іншого git-репозиторію: `install` пише в теку-споживача, зовнішній репозиторій не змінюється.
4. Вихідний код не компілюється: `npm pack` падає через `prepack`, smoke завершується не нулем, а не перевіряє старий `dist/`.
5. Запуск не з кореня (`node ../scripts/smoke.mjs` з підтеки): корінь береться з `import.meta.url`, а не з `cwd`.

### Задача 1: smoke-скрипт

**Файли:**
- Створити: `scripts/smoke.mjs`
- Змінити: `package.json` (`"smoke": "node scripts/smoke.mjs"`)

**Інтерфейси:**
- Дає: `npm run smoke`, код 0 якщо все пройшло, код 1 на першому провалі.

- [ ] **Крок 1.** Написати скрипт за розділом «Smoke» спеки, усі рядки таблиці перевірок. Рішення, яких спека не фіксує:
  - корінь: `fileURLToPath(new URL('..', import.meta.url))`;
  - тека: `mkdtempSync(join(tmpdir(), 'detent-smoke-'))`; всередині `pack/`, `consumer/`, `home/`;
  - запуск: `spawnSync(command, args, { cwd, env, encoding: 'utf8', shell: process.platform === 'win32' })`;
  - архів передавати npm відносним шляхом від `consumer/` (`../pack/<name>.tgz`), бо через shell абсолютний шлях із пробілом розпадеться;
  - ім'я архіву брати з `readdirSync(pack)`, бо `prepack` пише у stdout `npm pack`;
  - порожня домашня тека й очищені змінні лише для викликів `detent`; `npm` і `git init` працюють зі звичайним оточенням;
  - stdout `--version` порівнювати після `trim()`.
- [ ] **Крок 2.** Додати команду в `package.json`, запустити `npm run smoke`. Очікується: код 0, надруковано шлях теки.
- [ ] **Крок 3.** Коміт: `feat(smoke): check the packed detent in a temp folder`.
