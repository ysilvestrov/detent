# Кінець промо gpt-5.6-sol — план реалізації

> Виконання через superpowers:executing-plans, усі задачі інлайн: кожна торкається щонайбільше
> двох файлів і їхніх тестів, нових рішень не потребує, бо їх ухвалила спека. Один PR,
> harness-плану немає.

**Мета.** Рядок витрат не занижує рахунок ні до, ні після кінця промо `gpt-5.6-sol`; типова пара
`openai` стає `gpt-6.2-sol` + `gpt-6.2-sol`.

**Специфікація.** `docs/specs/2026-11/2026-11-23-gpt-5.6-sol-promo-end-design.md`, затверджено
власником 2026-11-23.

**Гейт після кожної задачі:** `npm run gate` у WSL-копії (typecheck, test, build).

## Задача 1. Датовані рядки цін (`usage.ts`, `usage.test.ts`)

- `PRICE_CHANGES: Record<string, readonly { from: string; price: Price }[]>`, запис
  `gpt-5.6-sol` від `2026-11-30T10:00:00Z`: `{ input: 5, cachedInput: 0.5, cacheWrite: 6.25,
  output: 30, flatUpTo: 272_000 }`.
- `priceAt(model, now): Price | undefined`: остання зміна з `Date.parse(from) <= now.getTime()`,
  інакше `PRICES[model]`.
- `costUsd(model, u, now = new Date())` бере ціну з `priceAt`.
- `PRICES_CHECKED_ON = '2026-11-23'`, коментар про промо: слова сторінки й межа.
- Тести: усі виклики `costUsd` з рядком, що має датовану зміну, передають `now`; межа з обох
  боків (`…T09:59:59.999Z` промо, `…T10:00:00.000Z` повна); `PRICE_CHANGES` упорядкований за
  зростанням `from` для кожної моделі.

## Задача 2. Межа тиру 272K (`usage.ts`, `usage.test.ts`, `openai.test.ts`)

- `Price.flatUpTo?: number`; `Usage.maxPromptTokens: number`, `EMPTY_USAGE` з нулем,
  `parseUsage` бере `prompt_tokens`, `addUsage` бере `Math.max`.
- `costUsd`: після захистів і `reportedUsd` — `null`, якщо `price.flatUpTo !== undefined &&
  u.maxPromptTokens > price.flatUpTo`.
- `flatUpTo: 272_000` на `gpt-5.5`, `gpt-5.6-sol`, `gpt-6.1-sol`, `gpt-6.1-terra` (і
  `gpt-6.2-sol` у задачі 3). Коментар таблиці: пошук тир не дістає, суддя дістає.
- Тести: 272 000 пласко, 272 001 `null`; `addUsage` бере більше; `reportedUsd` перемагає тир;
  фікстури з 1M вхідних токенів на 200 000 з літеральними очікуваннями; рукописні `Usage`
  отримують `maxPromptTokens`.

## Задача 3. Пара, кеш, рядок 6.2-sol (`providers.ts`, `usage.ts` і їхні тести)

- `PRICES['gpt-6.2-sol'] = { input: 2, cachedInput: 0.1, cacheWrite: 2.5, output: 10,
  flatUpTo: 272_000 }`.
- `defaultModels: { find: 'gpt-6.2-sol', verify: 'gpt-6.2-sol' }` з переписаним коментарем;
  `cacheOffModels` додає `gpt-6.2-sol`.
- Тести: `providers.test.ts` закріплює нову пару й список; рядок 6.2-sol закріплено літералом.
